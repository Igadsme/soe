# Render blueprint template — owner review required

This illustrative blueprint has not been applied. Applying it creates resources and may incur charges; this task authorizes neither. Verify current provider schema, plans, region, billing, pre-deploy availability and networking before use. Set all `sync: false` values securely. Supply a SQLAlchemy `postgresql+psycopg://` URL (provider URLs often need scheme conversion), Redis private URL, session secret and admin hash consistently to API/worker; use TLS when required by the database provider.

The web API is public in this initial template: metrics deliberately remain disabled. Build an owner-managed same-origin gateway for frontend and /api/*, /health, /ready; block /metrics there and restrict direct API ingress. Review trusted peer networks/header behavior. Set frontend's build-time URL and API CORS to that gateway origin. Shared media storage between API/worker is unresolved by this template and must be designed before processing uploads. Use existing storage/backups or an approved adapter; do not assume service-local disks are shared. Configure worker heartbeat monitoring, Redis/Postgres backups/PITR, encrypted off-site backups, secrets rotation, release serialization, resource limits, retention and external uptime alerts. The single pre-deploy migration command must be supported by the selected plan. All application images use backend/app; the unused scaffold is excluded.
